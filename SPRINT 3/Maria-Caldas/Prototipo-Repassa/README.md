# Repassa - Marketplace Universitário

Anexei a especificação completa do projeto (Requisitos Funcionais/Não Funcionais, Casos de Uso, Design System, Modelagem de Dados e Fluxograma de Telas).

Crie um protótipo funcional (React + Vite + Tailwind + shadcn) de "Repassa", um marketplace universitário de materiais acadêmicos usados, em português, mobile-first.

Nesta primeira iteração, implemente APENAS a Fase 1 e 2 descritas na seção 8 do documento:

- Fundação: tokens de cor, tipografia, variantes de botão/badge, layout com header + navegação inferior de 5 abas (Início, Buscar, Anunciar, Conversas, Perfil)

- Home: busca em destaque, categorias, grid de destaques

- Busca: com os filtros descritos (curso, categoria, preço, estado de conservação)

- Componente MaterialCard reutilizável, com todos os campos da seção 5.4/5.5 do documento

Use dados mock locais (sem backend nesta fase). Gere fotos de produtos com IA para os materiais mock. Não implemente ainda as próximas fases — vamos pedir uma de cada vez.
